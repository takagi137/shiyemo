# Feature: 环境音播放

## 场景：选择环境音播放

### 前置条件
- 用户已登录
- 访问 /sanctuary 页面
- 环境音模块已加载

### 测试步骤

1. 页面显示后端返回的环境音选项（默认 6 种：雨声、钢琴、森林、海浪、篝火、白噪音）
   - 列表由后端 `GET /api/v1/sounds` 提供（后端维护，可在 admin 增删改），前端不硬编码
2. 点击"雨声"选项

### 预期结果

- 开始播放雨声音频（循环 loop）
- 显示播放状态（正在播放：曲名）
- 音量默认 50%
- 其他选项显示为未选中状态

### 验证点

- [ ] 音频正常播放且循环
- [ ] 曲名显示正确

## 场景：暂停播放

### 前置条件
- 某环境音正在播放

### 测试步骤

1. 点击暂停按钮

### 预期结果

- 音频暂停播放
- 保持当前进度
- 暂停按钮变为播放按钮

## 场景：切换环境音

### 前置条件
- 雨声正在播放

### 测试步骤

1. 点击"海浪"选项

### 预期结果

- 停止雨声播放
- 开始播放海浪音
- 重置进度条
- 曲名更新为"海浪"

## 场景：调整音量

### 测试步骤

1. 拖动音量滑块到 80%

### 预期结果

- 音量实时变化
- 音量值保存到 localStorage
- 下次访问时恢复上次音量设置

## 场景：离开页面音频暂停

### 前置条件
- 环境音正在播放

### 测试步骤

1. 导航到其他页面

### 预期结果

- 音频自动暂停
- 保存当前播放状态到 localStorage
- 返回 /sanctuary 时恢复播放状态

## 场景：移动端环境音

### 前置条件
- 使用手机浏览器访问

### 测试步骤

1. 访问 /sanctuary
2. 选择环境音播放

### 预期结果

- 选项按钮大小适配触摸
- 音频正常播放
- 音量滑块可拖动

## 场景：音频加载失败时明确提示

### 前置条件
- 某音效的 url 不可达（如资源下线）

### 测试步骤

1. 点击该音效

### 预期结果

- 不切换到"正在播放"状态（不假装在播）
- 明确提示「XX 暂时放不出来 / 音频资源加载失败」
- 其他可用音效不受影响
