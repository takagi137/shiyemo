# Feature: 私密日记

## 场景：创建日记

### 前置条件
- 用户已登录（ID=1）
- 日记模块已加载

### 测试步骤

1. 发送 POST 请求到 `/api/v1/journal`
2. 请求头携带 `Authorization: Bearer <token>`
3. 请求体：
```json
{
  "content": "今天感觉好多了，阳光真好。"
}
```

### 预期结果

- HTTP 状态码：200
- 响应体：
```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "content": "今天感觉好多了，阳光真好。",
    "created_at": "2026-06-13T10:30:00Z"
  }
}
```

### 验证点

- [ ] 返回日记 id 和创建时间
- [ ] 数据库 journal 表新增一条记录
- [ ] user_id = 当前用户 id

## 场景：日记内容为空

### 测试步骤

1. 发送 POST 请求，content 为空字符串

### 预期结果

- HTTP 状态码：400
- 返回参数错误提示

## 场景：查看历史日记

### 前置条件
- 用户已有 3 条日记

### 测试步骤

1. 发送 GET 请求到 `/api/v1/journal`

### 预期结果

- HTTP 状态码：200
- 返回当前用户的所有日记（按时间倒序）
- 不返回其他用户的日记
- items 数组按 created_at 降序排列

## 场景：删除日记

### 前置条件
- 用户有日记（ID=1）

### 测试步骤

1. 发送 DELETE 请求到 `/api/v1/journal/1`

### 预期结果

- HTTP 状态码：200
- 日记被删除
- 再次查看时该日记不存在

## 场景：删除他人日记失败

### 前置条件
- 用户 A 有日记（ID=1）
- 用户 B 已登录

### 测试步骤

1. 用户 B 发送 DELETE 请求到 `/api/v1/journal/1`

### 预期结果

- HTTP 状态码：403 或 404
- 日记未被删除

## 场景：未登录访问日记 API

### 测试步骤

1. 不携带 token 发送 GET 请求到 `/api/v1/journal`

### 预期结果

- HTTP 状态码：401
- 返回"未授权"错误
