# Feature: 进入静思空间

## 场景：已登录用户访问静思空间

### 前置条件
- 用户已登录（token 有效）
- /sanctuary 页面存在

### 测试步骤

1. 发送 GET 请求到 `/sanctuary`
2. 请求头携带 `Authorization: Bearer <token>`

### 预期结果

- HTTP 状态码：200
- 页面加载完成
- 页面显示四个模块入口：
  - 呼吸练习
  - 环境音
  - 今日阅读
  - 私密日记
- 页面底部显示"返回社区 →"按钮
- 页面背景为柔和渐变色

### 验证点

- [ ] 页面不显示任何他人内容（帖子/头像/昵称）
- [ ] 页面不显示统计数据（发帖数/关注数等）
- [ ] 页面布局符合设计稿

## 场景：未登录用户访问静思空间

### 测试步骤

1. 不携带 token 访问 `/sanctuary`

### 预期结果

- 重定向到 `/login?redirect=/sanctuary`

## 场景：静思空间不暴露隐私信息

### 前置条件
- 用户已登录

### 测试步骤

1. 访问 `/sanctuary` 页面
2. 检查页面 DOM 元素

### 预期结果

- 页面不包含以下元素：
  - 其他用户的头像
  - 其他用户的昵称
  - 社区统计数据
  - 帖子列表
- 所有内容均为个人专属（呼吸/音乐/日记/阅读）
