# Feature: 今日阅读

## 前置条件
- readings 表中有多条经典内容（至少 5 条）
- 每条包含：原文 + 背景解读 + 作者 + 朝代

## 场景：获取今日阅读

### 测试步骤

1. 发送 GET 请求到 `/api/v1/readings/today`

### 预期结果

- HTTP 状态码：200
- 响应体包含：
  - id: 阅读条目 ID
  - source: 来源（如"苏轼《定风波》"）
  - author: 作者
  - content: 原文
  - interpretation: 背景解读
- 每天返回固定一篇（按日期轮换）

### 验证点

- [ ] 返回完整的阅读信息
- [ ] 内容非空
- [ ] 同一天多次请求返回同一篇

## 场景：随机获取阅读

### 测试步骤

1. 发送 GET 请求到 `/api/v1/readings/random`

### 预期结果

- HTTP 状态码：200
- 返回一篇随机阅读内容
- 格式与 today 接口一致

## 场景：readings 表为空

### 前置条件
- readings 表无数据

### 测试步骤

1. 发送 GET 请求到 `/api/v1/readings/today`

### 预期结果

- HTTP 状态码：200
- 返回默认文案："古人也曾在风雨中前行，你并不孤单。"
- 隐藏"下一篇"按钮的提示

## 场景：多次随机获取

### 测试步骤

1. 连续发送 5 次 GET `/api/v1/readings/random`

### 预期结果

- 每次返回的内容可能不同
- 所有返回格式一致
- 无重复内容（数据充足时）

## 场景：未登录访问阅读 API

### 测试步骤

1. 不携带 token 发送 GET 请求

### 预期结果

- HTTP 状态码：200（阅读内容可公开）
- 或 HTTP 状态码：401（如设计为需登录）
- 取决于产品设计决策
