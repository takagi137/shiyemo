# 首页温馨升级 — 产品设计

## 目标
让失业么从"社区"变成"避风港"。用户打开 App 的第一眼感受到的不是焦虑，而是**温暖、美、被理解**。

## 三个核心功能

### 1. 每日风景画（每日一景）
**概念：** 首页顶部展示一张全屏/半屏的风景图，每日更换。图片风格以宁静、治愈为主。

**实现方案：**
- 图片来源：Unsplash API（免费，高清摄影图库）
- 路线：后端 `/api/daily-image` 返回当天图片 URL + 描述
- 前端：Feed 页顶部轮播区域，支持多张图片自动切换
- 图片分类池：`nature, sunset, ocean, mountain, forest, flower, sky, cityscape`
- 用户可切换：点击换一张（同风格不同图）

**交互细节：**
- 首次加载显示今日推荐图
- 右下角"换一张"按钮，点击加载同类别另一张
- 图片上叠加一句每日一句（温暖的文案）
- 图片加载前显示渐变色占位（不闪白屏）

### 2. 每日贴士/温暖文案（Daily Tips）
**概念：** 在风景图下方展示一句精心设计的温暖文案，可以是：
- 励志短句
- 生活小贴士
- 正念/冥想引导
- 失业者的共鸣金句

**数据源：**
- 后端新增 `tips` 表，存文案库
- 管理后台可以新增/编辑/删除文案
- 每天随机选一条
- 也支持用户自己提交（P2）

**交互细节：**
- 文案居中显示，字号 18-20px，行高 1.6
- 文案下方有"换一条"按钮
- 风格：`"今天的你，已经比昨天勇敢了一点。"`
- 支持分享到社区

### 3. 背景音乐（Ambient Music）
**概念：** 用户可选择播放轻柔的背景音乐，营造安静的阅读/写作环境。

**实现方案：**
- 音乐来源：免费 CC 音乐库（如 freesound.org, pixabay.com/music）
- 存储：后端 `/api/music/list` 返回音乐列表（URL + 名称 + 时长）
- 前端：固定在页面右下角的小播放器（展开/收起）
- 用户控制：播放/暂停/切换/音量

**交互细节：**
- 默认静音，用户主动点击播放
- 播放器样式：小圆角卡片，半透明背景
- 显示当前曲名 + 播放进度
- 浏览器记忆上次播放状态（localStorage）
- 退出页面自动暂停

## 开发优先级

| 功能 | 优先级 | 改动范围 | 工作量 |
|------|--------|---------|--------|
| 每日风景画 | P0 | 后端（新增API）+ 前端（Feed顶部） | 中 |
| 每日贴士 | P0 | 后端（新增表+API）+ 管理后台 + 前端 | 中 |
| 背景音乐 | P1 | 后端（新增API）+ 前端（播放器组件） | 中 |

## 执行顺序
1. 首页风景图 + 每日贴士（一起做，视觉效果最大）
2. 背景音乐播放器
3. 管理后台：文案管理
