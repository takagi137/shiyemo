# 整体架构设计

> "失业么"项目的系统架构设计文档。
> 遵循"模块化单体 → 渐进式微服务"的演进路线。

---

## 产品定位

| 维度 | 内容 |
|------|------|
| **产品名** | 失业么 |
| **定位** | AI 时代个体"能力重建与收入重建"的社区与机会平台 |
| **核心用户** | 失业/待转型技术人、探索副业人群 |
| **北极星指标** | 项目发起数、合作次数、实际完成项目数 |

---

## 架构演进路线

| 阶段 | 用户规模 | 架构 | 说明 |
|------|---------|------|------|
| Phase1 (MVP) | 0-1 万 | 模块化单体 | 1 个 Go 服务，内部按模块组织 |
| Phase2 (增长) | 1-10 万 | 热点拆分 | 搜索、通知等模块拆为独立服务 |
| Phase3 (规模化) | 10-40 万+ | 微服务 | 全面微服务化，K8s 编排 |

## 模块划分

### 模块依赖关系

```
auth (认证)
  │
  ▼
user (用户)
  │
  ├─────▶ post (帖子)
  │         │
  ├─────▶ feed (信息流)  ◀───── post
  │
  └─────▶ interaction (互动) ◀───── post, user
             │
             └─────▶ notification (通知) [Phase2]
```

### 各模块职责

| 模块 | 职责 | 对外接口 |
|------|------|---------|
| auth | 注册、登录、Token 管理 | POST /api/v1/auth/register, /login |
| user | 用户资料、头像、技能标签 | GET/PUT /api/v1/users/:id |
| post | 帖子 CRUD、类型管理 | POST/GET/PUT/DELETE /api/v1/posts |
| feed | 信息流、排序、筛选 | GET /api/v1/feed |
| interaction | 点赞、收藏、关注 | POST /api/v1/posts/:id/like |
| search | 全文搜索 | GET /api/v1/search |

## API 路由设计

### 认证模块 (auth)

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/v1/auth/register | 用户注册 |
| POST | /api/v1/auth/login | 用户登录 |
| POST | /api/v1/auth/logout | 用户登出 |
| POST | /api/v1/auth/refresh | 刷新 Token |
| POST | /api/v1/auth/sms/send | 发送验证码 |

### 用户模块 (user)

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/v1/users/:id | 获取用户资料 |
| PUT | /api/v1/users/:id | 更新用户资料 |
| POST | /api/v1/users/avatar | 上传头像 |
| GET | /api/v1/users/:id/posts | 获取用户帖子列表 |
| GET | /api/v1/users/:id/followers | 获取粉丝列表 |
| GET | /api/v1/users/:id/following | 获取关注列表 |

### 帖子模块 (post)

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/v1/posts | 发布帖子 |
| GET | /api/v1/posts/:id | 获取帖子详情 |
| PUT | /api/v1/posts/:id | 编辑帖子 |
| DELETE | /api/v1/posts/:id | 删除帖子（软删除） |
| GET | /api/v1/posts/:id/comments | 获取评论列表 |
| POST | /api/v1/posts/:id/comments | 发表评论 |

### Feed 模块 (feed)

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/v1/feed | 获取信息流 |
| GET | /api/v1/feed/hot | 热门帖子 |
| GET | /api/v1/feed/latest | 最新帖子 |

Query 参数：
- `type`：筛选类型 (emotion/insight/case/action)
- `sort`：排序方式 (latest/hot)
- `page`：页码（从 1 开始）
- `size`：每页数量（默认 20，最大 50）

### 互动模块 (interaction)

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/v1/posts/:id/like | 点赞/取消点赞 |
| POST | /api/v1/posts/:id/bookmark | 收藏/取消收藏 |
| POST | /api/v1/users/:id/follow | 关注/取消关注 |
| POST | /api/v1/comments/:id/like | 点赞评论 |

### 搜索模块 (search)

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/v1/search/posts | 搜索帖子 |
| GET | /api/v1/search/users | 搜索用户 |

## 前端路由设计

```
/                           # 首页（Feed 流）
/login                      # 登录页
/register                   # 注册页
/post/create                # 发帖页
/post/:id                   # 帖子详情页
/post/:id/edit              # 编辑帖子页
/profile/:id                # 用户主页
/profile/:id/posts          # 用户帖子列表
/profile/:id/likes          # 用户点赞列表
/profile/me                 # 个人中心（已登录）
/profile/me/settings        # 设置页
/search                     # 搜索页
/search?q=xxx               # 搜索结果页
```

## 数据流转

### 发帖流程

```
用户填写表单 → 前端校验 → POST /api/v1/posts
                              │
                    ┌─────────▼─────────┐
                    │    API 层 (Gin)    │
                    │  - JWT 认证        │
                    │  - 参数校验        │
                    └─────────┬─────────┘
                              │
                    ┌─────────▼─────────┐
                    │  Service 层        │
                    │  - 业务逻辑        │
                    │  - 权限检查        │
                    └─────────┬─────────┘
                              │
                    ┌─────────▼─────────┐
                    │    Repo 层         │
                    │  - 数据入库        │
                    │  - 返回结果        │
                    └─────────┬─────────┘
                              │
                    ┌─────────▼─────────┐
                    │   PostgreSQL      │
                    │  posts 表插入      │
                    └─────────┬─────────┘
                              │
                    ┌─────────▼─────────┐
                    │ 后续异步处理       │
                    │  - 更新 Feed 缓存  │
                    │  - 推入搜索索引    │
                    │  - 更新发帖计数    │
                    └───────────────────┘
```
