# 功能矩阵与优先级

## MVP 优先级（P0 = 必须做，P1 = 应该做，P2 = 可以后做）

### 用户系统

| 功能 | 优先级 | 说明 |
|------|:------:|------|
| 邮箱注册/登录 | P0 | 基础能力 |
| 手机号注册/登录 | P0 | 国内用户主流方式 |
| 个人资料（昵称/头像/简介） | P0 | 基础社交能力 |
| 技能标签 | P1 | 用户画像基础，匹配依赖 |
| 第三方登录（微信） | P2 | 增长期再做 |

### 内容系统

| 功能 | 优先级 | 说明 |
|------|:------:|------|
| 发布帖子（4 种类型） | P0 | 核心能力 |
| 富文本编辑器 | P0 | 图文混排 |
| 图片上传 | P0 | 视觉表达 |
| 话题/标签分类 | P0 | 内容发现基础 |
| 内容审核（基础敏感词） | P1 | 合规要求 |

### 互动系统

| 功能 | 优先级 | 说明 |
|------|:------:|------|
| 点赞 | P0 | 基础反馈 |
| 评论（两级） | P0 | 讨论基础 |
| 收藏 | P0 | 个人内容管理 |
| 关注用户 | P1 | 社交关系 |
| 分享（链接/海报） | P1 | 增长渠道 |

### 信息流

| 功能 | 优先级 | 说明 |
|------|:------:|------|
| 首页 Feed（最新/最热） | P0 | 核心浏览体验 |
| 按类型筛选 | P0 | 定向浏览 |
| 按标签筛选 | P1 | 精准发现 |
| 无限滚动加载 | P0 | 移动端体验 |

### 搜索

| 功能 | 优先级 | 说明 |
|------|:------:|------|
| 全文搜索（帖子/用户） | P1 | Meilisearch |
| 搜索建议 | P2 | 体验优化 |

### 通知系统

| 功能 | 优先级 | 说明 |
|------|:------:|------|
| 站内通知（点赞/评论/关注） | P1 | 基础通知 |
| 未读计数 | P1 | 提醒回访 |

### 个人中心

| 功能 | 优先级 | 说明 |
|------|:------:|------|
| 我的帖子 | P0 | 内容管理 |
| 我的收藏 | P0 | 个人空间 |
| 我的点赞 | P1 | 浏览历史 |
| 编辑资料 | P0 | 基础能力 |

### 管理后台

| 功能 | 优先级 | 说明 |
|------|:------:|------|
| 内容管理（审核/隐藏/删除） | P1 | 运营基础 |
| 用户管理 | P2 | 后期需要 |
| 数据统计 | P2 | 决策依据 |

---

## 延后功能（明确不做）

| 功能 | 计划阶段 | 原因 |
|------|---------|------|
| 行动类型扩展（项目详情/参与者管理） | Phase 2 | 需要用户基础验证 |
| 即时通讯（私信） | Phase 2 | 复杂度高，MVP 用不到 |
| 推荐算法 | Phase 2 | 内容量小时无意义 |
| 项目撮合 | Phase 3 | 需要双方用户基础 |
| 支付系统 | Phase 3 | 法律合规复杂 |
| B 端需求发布 | Phase 3 | 需要 C 端用户基础 |
| 移动端 App | Phase 2 | Web 验证后再说 |
| 微信小程序 | Phase 2 | 增长渠道，非核心 |
