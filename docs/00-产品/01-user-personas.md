# 用户画像

## 目标用户

### 核心用户（Phase 1）

#### 画像 A：被动失业的技术人

- **年龄**：28-40 岁
- **背景**：互联网/科技公司中层，技术能力强但依赖平台
- **现状**：被裁员 1-6 个月，有储蓄但焦虑日增
- **心理**：自我怀疑、焦虑，偶尔恐惧，但内心仍想折腾
- **需求**：重新定位自己的能力，找到新的收入方向
- **核心场景**：浏览 insight 内容、加入 action 项目

#### 画像 B：主动探索副业的在职人

- **年龄**：25-35 岁
- **背景**：在职但感受到 AI 替代压力，想提前准备
- **现状**：有收入但缺乏安全感
- **心理**：焦虑但清醒，想提前布局
- **需求**：找到可执行的副业方向，找到靠谱的合作伙伴
- **核心场景**：发起 action 项目、发布 case 分享

### 扩展用户（Phase 2+）

#### 画像 C：需求方

- **背景**：中小企业主或项目负责人
- **需求**：找到性价比高的人才完成具体项目
- **价值**：为平台用户带来真实收入机会

---

## 用户旅程

```
发现 → 注册 → 浏览/共鸣 → 学习/思考 → 参与行动 → 收入 → 分享
```

### 典型旅程示例

1. 小李被裁员，朋友分享了一篇帖子
2. 打开"失业么"，看到"我被优化了"的情绪帖子，感到共鸣
3. 浏览更多内容，看到"AI 帮我接了第一单"的案例
4. 受启发，看到一个"一起做独立项目"的行动帖，点击参与
5. 加入项目，和陌生人一起做出产品
6. 获得收入，发布自己的案例帖

---

## 用户心理模型

用户处于人生低谷，最需要的是 **安全感 → 希望感 → 方向感 → 掌控感**。

- 不要居高临下
- 不要贩卖焦虑
- 不要空洞口号
- 要真实、具体、可行动
