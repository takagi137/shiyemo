# 失业么 - 系统设计概览

> 快速了解系统主要功能、模块划分、技术架构与中间件选型。

---

## 1. 产品定位

| 维度 | 说明 |
|------|------|
| **产品名** | 失业么 |
| **定位** | AI 时代个体"能力重建与收入重建"社区平台 |
| **核心机制** | 情绪共鸣 → 认知构建 → 行动发起 → 项目孵化 |
| **目标用户** | 失业/待转型技术人、探索副业人群 |
| **北极星指标** | 项目发起数、合作次数、实际完成项目数 |

## 5. 中间件详解

### 5.1 PostgreSQL - 主数据库

**用途**：存储核心业务数据

| 表 | 说明 |
|-----|------|
| users | 用户信息 |
| posts | 帖子内容 |
| comments | 评论 |
| likes | 点赞记录 |
| bookmarks | 收藏记录 |
| follows | 关注关系 |
| tags | 标签 |

**特性**：
- JSONB 存储扩展字段
- 全文搜索（可选，Meilisearch 更优）
- 事务支持
- 丰富的索引类型

---

### 5.2 Redis - 缓存层

**用途**：

| 场景 | Key 格式 | TTL |
|------|---------|-----|
| 验证码 | `sms:{phone}` | 5 分钟 |
| 发送频率 | `sms:limit:{phone}` | 60 秒 |
| 用户 Session | `session:{user_id}` | 7 天 |
| Feed 缓存 | `feed:{user_id}:{page}` | 5 分钟 |
| 热门帖子 | `hot:posts` | 10 分钟 |
| 点赞计数 | `post:{id}:likes` | 持久化 |
| 关注关系 | `user:{id}:followers` | 持久化 |

**特性**：
- 高性能读写
- 自动过期
- 原子操作

---

### 5.3 Meilisearch - 搜索引擎

**用途**：全文搜索、中文分词

| 索引 | 说明 | 可搜索字段 |
|------|------|-----------|
| posts | 帖子搜索 | title, content, tags |
| users | 用户搜索 | nickname, bio, skills |

**特性**：
- 轻量级（单二进制文件）
- 中文分词支持
- 近实时索引
- 容错搜索
- 排序与过滤

---

### 5.4 Caddy - 反向代理

**用途**：

| 功能 | 说明 |
|------|------|
| HTTPS | 自动 Let's Encrypt 证书 |
| 反向代理 | 转发 API 请求到 Go 后端 |
| 静态资源 | 服务 Next.js 构建产物 |
| 负载均衡 | Phase2+ 多实例 |

**配置示例**：

```
shiyemo.com {
    # API 请求
    handle /api/* {
        reverse_proxy localhost:8080
    }
    
    # 静态资源
    handle {
        reverse_proxy localhost:3000
    }
    
    # 自动 HTTPS
    tls internal
}
```

---

### 5.5 MinIO / Aliyun OSS - 对象存储

**用途**：存储图片、文件等静态资源

| 类型 | 说明 |
|------|------|
| 用户头像 | avatar/{user_id}/avatar.jpg |
| 帖子图片 | post/{post_id}/{image_id}.jpg |
| 临时文件 | tmp/{date}/{filename} |

**特性**：
- S3 兼容 API
- 海量存储
- CDN 加速

## 6. API 设计规范

### 6.1 统一响应格式

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

### 6.2 错误码规范

| 类别 | 范围 | 示例 |
|------|------|------|
| 参数错误 | 400xx | 40001 参数错误 |
| 认证错误 | 401xx | 40101 未登录 |
| 用户错误 | 402xx | 40201 手机号已注册 |
| 帖子错误 | 403xx | 40301 帖子不存在 |
| 服务错误 | 500xx | 50001 数据库错误 |

### 6.3 分页规范

```
GET /api/v1/posts?page=1&size=20&sort=latest&type=emotion

Response:
{
  "code": 0,
  "data": {
    "list": [...],
    "page": 1,
    "size": 20,
    "has_more": true
  }
}
```

## 7. 安全设计

### 7.1 认证

| 方式 | 说明 |
|------|------|
| JWT Token | 7 天有效期，自动续期 |
| 密码加密 | bcrypt，cost=10 |
| 验证码 | 6 位数字，5 分钟有效 |
| 发送频率 | 60 秒/次 |

### 7.2 接口保护

| 类型 | 说明 |
|------|------|
| 公开接口 | 注册、登录、帖子列表 |
| 认证接口 | 发帖、点赞、收藏 |
| 权限接口 | 删除自己的帖子、编辑个人资料 |
