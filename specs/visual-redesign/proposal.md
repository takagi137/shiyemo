# proposal：前端视觉重做

> 状态：**待评审**
> 创建时间：2026-07-20

## 背景

用户反馈「前端设计得不太好，界面和美化上差很大，也不够对用户友好」。

排查后发现问题分两层，性质完全不同：

### 第一层：设计系统丢失（已修复，非本提案范围）

2026-05-28 前端从 Tailwind v3 迁到 v4 时 `globals.css` 被重置为默认模板，
`card` / `btn-primary` / `btn-secondary` / `input-field` 四个类的定义丢失，
而 18 个页面共 136 处仍在引用。结果是全站卡片无背景无边框、按钮为浏览器默认样式。

该问题已在提交 `b18ee0a` 修复并部署验证。**本提案不重复处理。**

### 第二层：设计语言与产品调性不匹配（本提案范围）

即便恢复了设计系统，现有视觉仍是「Tailwind 默认蓝 + emoji 图标」的通用后台风格：

| 现状 | 问题 |
|------|------|
| 主色 `blue-600` | 通用 SaaS/后台色，缺少温度 |
| 画布 `gray-50` 冷灰 | 偏"工具"观感，不适合长时间停留 |
| 5 种帖子类型用 5 个高饱和撞色<br>(rose/amber/blue/emerald/yellow) | 并排出现在信息流里互相争夺注意力，盖过内容本身 |
| emoji 当功能图标（🤝💡📖🚀🏆👍💬） | 跨平台字形不一致、彩色饱和度高、风格偏幼态 |
| 未声明 CJK 字体栈 | Geist 不含中文字形，中文一直 fallback 到系统默认（常为宋体） |
| 卡片 hover 位移 + 投影 | 信息流中连续出现时视觉躁动 |

产品内核是「AI 时代个体的能力重建社区」，首页文案写着
「在这里，没有人在催你」「慢慢来，你已经在路上了」。
目标用户是处于失业焦虑中的个体。当前视觉与这套主张是割裂的。

## 目标用户

- 失业/待转型个体，处于焦虑或低能量状态
- 使用场景多为长时间浏览、反复回访，而非快速完成任务

## 核心功能

1. **建立语义化设计令牌**：canvas / surface / ink / line / accent 等，
   替代散落各页面的 Tailwind 原子色，使后续调整可集中进行
2. **主色替换**：深鼠尾草绿。不用蓝（无温度）、不用红橙（对焦虑人群带警示意味）
3. **暖调画布**：冷灰改暖白
4. **帖子类型色统一**：5 种类型收敛到同一明度与彩度，仅以色相区分
5. **线性图标替换 emoji**：统一 24×24 网格、继承 currentColor
6. **CJK 字体栈**：显式声明中文字体，覆盖主流桌面与移动端
7. **交互降噪**：卡片 hover 去掉位移，仅保留极轻微描边/投影变化

## 不做范围（明确延后）

- **深色模式**：当前 body 硬编码浅色背景，改造面大，延后
- **移动端底部导航**：属于信息架构调整，非视觉范畴，另开提案
- **Feed 无限滚动替换分页**：交互模式变更，另开提案
- **全局 auth context**（登录后导航栏不刷新的缺陷）：属功能缺陷，另开提案
- **静思空间 / 管理后台的深度定制**：先铺主链路，这两处沿用新令牌即可

## 成功标准

- [ ] 全站不再直接引用 `blue-*` / `gray-*` 原子色，统一走语义令牌
- [ ] 5 种帖子类型标签在同一屏并排出现时，无单一颜色明显跳脱
- [ ] 功能性 emoji 全部替换为线性图标（心情表情除外——它表达的就是表情本身）
- [ ] 中文在 Windows / macOS / iOS / Android 上均以无衬线字体渲染，非宋体
- [ ] 主链路页面（feed / 帖子详情 / 发帖 / 登录注册 / 个人中心）视觉一致
- [ ] 色彩对比度满足 WCAG AA（正文 4.5:1，大字号 3:1）
- [ ] 前端构建通过，既有 105 个前端测试用例全部通过

## 当前进度与已知缺陷

已完成一个**未经本流程评审**的样本（提交 `09eaed7`，已部署至 8090 验证环境），
覆盖 globals.css 令牌层、Icon 组件、constants.ts 配色、feed 页、Navbar。

**已知缺陷（待修）**：
feed 页筛选行使用了无效的 Tailwind 任意变体语法
`[&::-webkit-scrollbar]{display:none}`（花括号形式不被支持），
导致筛选按钮与排序控件重叠，「行动发起」「成果展示」不可见。

该样本仅作为设计方向的可视化依据，**是否保留取决于本提案评审结果**。

## 待评审决策点

1. **是否接受深鼠尾草绿作为主色**？备选：暖陶土色（更温暖但偏警示）、
   深靛蓝（保守，接近现状）
2. **是否接受「幼苗」作为成果展示图标**（而非奖杯）？
   幼苗更贴合「学会做饭也是成果」的产品主张，但辨识度略低于奖杯
3. **铺开范围**：先做主链路 5 个页面，还是一次性覆盖全部 21 个路由？
