# spec：设计令牌在构建产物中生效

> 所属模块：前端设计系统
> 优先级：P0
> 创建时间：2026-07-21

## 场景描述

设计令牌与组件类必须真实出现在构建后的 CSS 产物中。
此场景专为防止「globals.css 定义丢失但构建仍通过」这类静默失效
（2026-05-28 曾潜伏两月未被发现）。

## 规格

### Given 已按新设计系统修改 globals.css

- globals.css 定义了语义令牌 canvas/surface/ink/accent 及五类标签色
- 定义了 card / btn-primary / btn-secondary / input-field 组件类

### When 执行生产构建

- `next build` 成功
- 定位 `.next/static` 下的 CSS 产物

### Then 令牌与组件类均已生成

- CSS 产物中存在 `--color-accent`，其值解析为深绿（非蓝）
- CSS 产物中存在 `--color-canvas`，其值为暖白（非纯白/冷灰）
- `.card` / `.btn-primary` / `.btn-secondary` / `.input-field` 四个选择器均存在
- 五类标签令牌 `--color-emotion-*` … `--color-achievement-*` 均存在

## 验证方式

| 验证项 | 方式 | 预期值 |
|--------|------|--------|
| 构建 | `next build` | 成功，无 error |
| accent 令牌 | grep CSS 产物 | `--color-accent:#2e6b53` 或等价 oklch |
| 四组件类 | grep CSS 产物 | 4 个选择器全部命中 |
| 标签令牌 | grep CSS 产物 | 15 个 `--color-{类型}-{层}` 全部命中 |
