# spec：主链路页面无旧色与功能性 emoji 残留

> 所属模块：前端设计系统
> 优先级：P0
> 创建时间：2026-07-21

## 场景描述

主链路 5 页及其关联组件完成重做后，不应再直接引用 Tailwind 原子色
（blue-/gray-/rose-/amber-/emerald-/indigo-/purple-），也不应再用 emoji
充当功能图标。这是「视觉一致」这一成功标准的可自动化检查形式。

## 规格

### Given 主链路页面已按 design.md 完成重做

- 涉及文件：feed/page、posts/[id]/page、posts/create/page、
  login/page、register/page、profile/page，
  及组件 PostCard、LoginForm、RegisterForm、Navbar

### When 对这些文件做静态扫描

- grep 原子色类名：`(blue|gray|rose|amber|emerald|indigo|purple)-[0-9]`
- grep 功能性 emoji（心情表情 MOOD 除外）

### Then 无残留

- 原子色类名命中数为 0
- 功能性 emoji 命中数为 0（👍💬🔮💧📌 等替换为 Icon 组件）
- 例外：心情 emoji（😊😌😢😠😰）保留——它表达的是表情本身，非功能图标

## 验证方式

| 验证项 | 方式 | 预期值 |
|--------|------|--------|
| 原子色残留 | grep 5 页+4 组件 | 0 命中 |
| 功能 emoji 残留 | grep（排除 MOOD） | 0 命中 |
| 心情 emoji | 人工确认 | 保留 |
