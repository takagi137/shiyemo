# spec：feed 筛选行布局不重叠

> 所属模块：Feed 流
> 优先级：P0
> 创建时间：2026-07-21

## 场景描述

修复样本引入的缺陷：feed 页筛选按钮行使用了无效的 Tailwind 任意变体语法
`[&::-webkit-scrollbar]{display:none}`，导致横向溢出未被约束，
筛选按钮与右侧「最新/最热」排序控件重叠，部分类型按钮不可见。

## 规格

### Given 用户打开 feed 页

- 屏幕宽度为常见桌面宽度（≥1024px）与移动宽度（375px）
- 筛选选项共 8 个（全部/关注/同温层 + 5 种帖子类型）

### When 页面渲染筛选行

- 筛选按钮区在左，排序控件（最新/最热）在右

### Then 布局正确不重叠

- 排序控件完整可见，不被筛选按钮压盖
- 筛选按钮区在空间不足时横向滚动，而非换行或溢出压盖其他元素
- 所有 8 个筛选按钮可通过滚动访问到
- 桌面宽度下筛选按钮与排序控件之间有可见间距

## 验证方式

| 验证项 | 方式 | 预期值 |
|--------|------|--------|
| 桌面截图 | headless Chrome 1280px | 排序控件可见，无重叠 |
| 移动截图 | headless Chrome 375px | 筛选行不压盖，可横向滚动 |
| 语法有效性 | grep | 无 `[&...]{...}` 花括号形式残留 |
