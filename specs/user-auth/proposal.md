# proposal：用户注册/登录功能

## 背景

- 当前用户无法创建账户，无法使用核心功能（发帖、评论、点赞等）
- 需要支持两种登录方式：
  - 手机号 + 验证码
  - 邮箱 + 密码
- MVP 阶段手机验证码使用 mock 模式（固定 123456）

## 目标用户

- 首次使用"失业么"的用户
- 已有账户需要登录的用户

## 核心功能

1. **邮箱注册**：用户输入邮箱 + 密码 + 昵称完成注册
2. **手机号注册**：用户输入手机号 + 验证码 + 昵称完成注册
3. **邮箱登录**：用户输入邮箱 + 密码登录
4. **手机号登录**：用户输入手机号 + 验证码登录
5. **验证码发送**：发送验证码到手机号（MVP 阶段 mock 固定 123456）
6. **Token 管理**：登录成功后返回 JWT token，支持 token 刷新

## 不做范围

- 第三方登录（微信/GitHub）：延后到 Phase2
- 邮箱验证码：延后到 Phase2
- 密码找回/重置：延后到 Phase2
- 邀请注册：延后到 Phase2
- 图形验证码：延后到 Phase2

## 成功标准

- [ ] 用户能通过邮箱 + 密码完成注册
- [ ] 用户能通过手机号 + 验证码完成注册
- [ ] 用户能通过邮箱 + 密码登录
- [ ] 用户能通过手机号 + 验证码登录
- [ ] 注册成功后返回 JWT token
- [ ] 重复邮箱注册返回明确错误信息
- [ ] 重复手机号注册返回明确错误信息
- [ ] 密码错误返回明确错误信息
- [ ] 验证码错误返回明确错误信息

## 用户表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键，自增 |
| phone | VARCHAR(20) | 手机号，唯一，可空 |
| email | VARCHAR(255) | 邮箱，唯一，可空 |
| nickname | VARCHAR(50) | 昵称，必填 |
| avatar_url | TEXT | 头像URL，可空 |
| bio | TEXT | 个人简介，可空 |
| company | VARCHAR(100) | 前公司，可空 |
| occupation | VARCHAR(100) | 职业，可空 |
| skill_tags | JSONB | 技能标签数组，默认空数组 |
| password_hash | VARCHAR(255) | 密码哈希（邮箱注册必填） |
| status | INT | 0=禁用 1=正常，默认1 |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |
| deleted_at | TIMESTAMPTZ | 软删除时间 |
