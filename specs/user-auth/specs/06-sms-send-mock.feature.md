# spec：发送验证码 - Mock 模式

> 所属模块：认证 (auth)
> 优先级：P0

## 场景描述

MVP 阶段，发送验证码接口直接返回成功，验证码固定为 123456。

## 规格

### Given 系统运行在 MVP 模式
- 短信服务为 mock 模式
- 手机号 13800138000 未在 60 秒内请求过验证码

### When 用户请求发送验证码
- 请求：POST /api/v1/auth/sms/send
- 请求体：
  ```json
  {
    "phone": "13800138000"
  }
  ```

### Then 发送成功
- 响应状态码：200
- 响应体：
  ```json
  {
    "code": 0,
    "message": "验证码已发送",
    "data": null
  }
  ```
- 验证码 123456 存储在 Redis 中，有效期 5 分钟
