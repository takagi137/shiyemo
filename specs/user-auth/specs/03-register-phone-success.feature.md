# spec：手机号注册 - 成功场景

> 所属模块：认证 (auth)
> 优先级：P0

## 场景描述

新用户使用手机号 + 验证码成功注册账户（MVP 阶段验证码固定为 123456）。

## 规格

### Given 用户满足注册条件
- 用户未登录
- 手机号 13800138000 未被注册
- 验证码 123456 已发送（mock 模式）

### When 用户提交注册请求
- 请求：POST /api/v1/auth/register/phone
- 请求体：
  ```json
  {
    "phone": "13800138000",
    "code": "123456",
    "nickname": "测试用户"
  }
  ```

### Then 注册成功
- 响应状态码：200
- 响应体包含 token 和 user 对象
- 数据库 `users` 表新增 1 条记录
- `phone` = "13800138000"
