# proposal：首页温馨升级

## 背景
- 当前首页（`/`）是一个纯产品介绍页，功能完整但缺乏情感温度
- 用户打开失业么的第一眼，应该感受到**温暖、宁静、被理解**，而不是焦虑
- Feed 页（`/feed`）包含社区内容，但首页不应该直接暴露帖子，避免压力

## 目标用户
- 所有用户（已登录/未登录）
- 新用户首次访问
- 老用户日常访问

## 核心功能
1. **每日风景图**：首页顶部展示全屏风景图，每日更换，营造宁静氛围
2. **每日温暖文案**：风景图上叠加一句温暖的话，每日更换
3. **进入社区入口**：柔和的按钮引导进入 Feed 页
4. **产品理念展示**：简洁传达"在这里，没有人在催你"

## 不做范围
- 首页不展示任何他人帖子/内容
- 不实现 Feed 页的背景音乐（后续单独做）
- 不实现静思空间（后续单独做）

## 成功标准
- [ ] 首页加载后展示全屏风景图 + 温暖文案
- [ ] 风景图每日自动更换
- [ ] 文案每日自动更换
- [ ] 点击"进入社区"跳转到 /feed
- [ ] 未登录用户也能看到首页
- [ ] 移动端和桌面端都能正常显示
- [ ] 页面加载时间 < 2s（含图片懒加载）
