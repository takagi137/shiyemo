# spec：首页 - 风景图展示

## 场景描述
用户访问首页时，看到全屏风景图和温暖文案

## 规格

### Given 首页内容已准备
- Unsplash API 可用
- tips 表中至少有 1 条文案
- Redis 缓存中有今日风景图

### When 用户访问首页 GET /
- 页面加载完成

### Then 首页展示风景图
- 页面顶部展示全屏风景图
- 图片加载前显示渐变色占位（不闪白屏）
- 风景图上叠加温暖文案
- 文案字号 18-20px，行高 1.6，白色文字+阴影
- 文案下方显示"进入社区 →"按钮
- 页面下方显示产品理念文案

### When 风景图加载失败
- 显示默认渐变背景（蓝紫色调）
- 文案仍然正常显示
- 不影响页面其他功能
