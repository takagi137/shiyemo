# 场景：管理员用户管理

## 场景 1：管理员获取用户列表

### 前置条件
- 用户是管理员

### 测试步骤
1. 发送 GET 请求到 `/api/v1/admin/users?page=1&page_size=20`

### 预期结果
- 状态码：200
- 返回用户列表

---

## 场景 2：管理员禁用用户

### 前置条件
- 存在一个正常用户

### 测试步骤
1. 发送 PUT 请求到 `/api/v1/admin/users/:id/status`
2. Body: {"status": 0}

### 预期结果
- 状态码：200
- 用户状态变为禁用

---

## 场景 3：管理员启用用户

### 前置条件
- 存在一个禁用用户

### 测试步骤
1. 发送 PUT 请求到 `/api/v1/admin/users/:id/status`
2. Body: {"status": 1}

### 预期结果
- 状态码：200
- 用户状态变为启用
