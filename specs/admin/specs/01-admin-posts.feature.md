# 场景：管理员帖子管理

## 场景 1：管理员获取帖子列表

### 前置条件
- 用户是管理员
- 平台有多个帖子

### 测试步骤
1. 发送 GET 请求到 `/api/v1/admin/posts?page=1&page_size=20`
2. 携带管理员 JWT token

### 预期结果
- 状态码：200
- 返回帖子列表

---

## 场景 2：普通用户无法访问

### 前置条件
- 用户不是管理员

### 测试步骤
1. 发送 GET 请求到 `/api/v1/admin/posts`

### 预期结果
- 状态码：403

---

## 场景 3：管理员删除帖子

### 前置条件
- 存在一个帖子

### 测试步骤
1. 发送 DELETE 请求到 `/api/v1/admin/posts/:id`

### 预期结果
- 状态码：200
- 帖子被软删除
