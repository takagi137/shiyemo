# Feature: 收藏列表

## 场景：获取用户收藏列表

### 前置条件
- 用户已登录（ID=1）
- 用户有收藏的帖子

### 测试步骤

1. 发送 GET 请求到 `/api/v1/users/1/bookmarks?page=1&size=20`
2. 请求头携带 `Authorization: Bearer <token>`

### 预期结果

- HTTP 状态码：200
- 响应体包含分页数据
- 列表包含收藏的帖子信息

### 验证点

- [x] 返回分页数据
- [x] 包含帖子详细信息
- [x] 按收藏时间倒序排列

## 场景：空收藏列表

### 前置条件
- 用户无收藏

### 测试步骤

1. 发送 GET 请求

### 预期结果

- 返回空列表
