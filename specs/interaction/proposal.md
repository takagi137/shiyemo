# proposal：点赞/收藏功能

## 需求背景

用户可以对帖子进行点赞和收藏，表示认可或保存。
点赞和收藏是社区互动的核心功能。

## 用户故事

1. 作为已登录用户，我希望点赞帖子，以便表示认可
2. 作为已登录用户，我希望收藏帖子，以便以后查看
3. 作为已登录用户，我希望取消点赞/收藏
4. 作为访客，我希望看到帖子的点赞数

## 功能范围

### MVP 阶段（本次实现）

- [ ] 点赞帖子
- [ ] 取消点赞
- [ ] 收藏帖子
- [ ] 取消收藏
- [ ] 查询是否已点赞/收藏
- [ ] 查询用户的收藏列表

### 后续迭代

- [ ] 点赞评论
- [ ] 收藏夹分类

## 验收标准

1. 已登录用户可以点赞/收藏帖子
2. 重复点赞/收藏返回成功（幂等）
3. 取消点赞/收藏返回成功
4. 帖子详情包含点赞数
5. 用户可以查看自己的收藏列表

## 技术约束

- 遵循 handler → service → repo 分层
- 使用独立的 likes 和 bookmarks 表
- 使用联合唯一索引防止重复
