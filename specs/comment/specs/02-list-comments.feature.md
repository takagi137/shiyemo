# Feature: 获取评论列表

## 场景：获取帖子评论列表

### 前置条件
- 帖子存在（ID=1）
- 帖子有评论

### 测试步骤

1. 发送 GET 请求到 `/api/v1/posts/1/comments?page=1&size=20`

### 预期结果

- HTTP 状态码：200
- 响应体包含分页数据
- 评论按时间正序排列
- 主评论包含 replies 数组

### 验证点

- [x] 返回分页数据
- [x] 评论按时间正序排列
- [x] 主评论包含 replies
- [x] 包含作者信息

### 测试步骤
