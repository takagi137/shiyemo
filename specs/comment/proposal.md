# proposal：评论功能

## 需求背景

用户可以对帖子发表评论，支持最多两级评论（主评论 + 回复）。
评论是社区互动的重要组成部分。

## 用户故事

1. 作为已登录用户，我希望对帖子发表评论，以便表达我的看法
2. 作为已登录用户，我希望回复其他人的评论，以便进行讨论
3. 作为访客，我希望查看帖子的评论列表，以便了解讨论内容
4. 作为已登录用户，我希望删除自己的评论，以便移除不当内容

## 功能范围

### MVP 阶段（本次实现）

- [ ] 发表评论（主评论）
- [ ] 回复评论（二级评论）
- [ ] 获取帖子评论列表
- [ ] 删除评论（软删除）

### 后续迭代

- [ ] 评论点赞
- [ ] 评论排序
- [ ] 评论通知

## 验收标准

1. 已登录用户可以对帖子发表评论
2. 评论创建成功后返回完整信息
3. 支持回复其他评论（最多两级）
4. 任何用户可以查看帖子的评论列表
5. 只有作者可以删除自己的评论
6. 删除后评论不再显示

## 技术约束

- 遵循 handler → service → repo 分层
- 评论存储在 PostgreSQL
- 支持最多两级评论（主评论 + 回复）
- 使用软删除
