# proposal：搜索功能

## 需求背景

用户可以搜索帖子和用户。
搜索是内容发现的重要功能。

## 用户故事

1. 作为用户，我希望搜索帖子，以便找到感兴趣的内容
2. 作为用户，我希望搜索用户，以便找到想关注的人
3. 作为用户，我希望按关键词搜索

## 功能范围

### MVP 阶段（本次实现）

- [ ] 搜索帖子（标题、内容）
- [ ] 搜索用户（昵称）
- [ ] 分页返回结果

### 后续迭代

- [ ] 搜索建议
- [ ] 热门搜索
- [ ] 搜索历史

## 验收标准

1. 用户可以通过关键词搜索帖子
2. 用户可以通过关键词搜索用户
3. 搜索结果支持分页
4. 搜索结果按相关性排序

## 技术约束

- 使用 Meilisearch 进行全文搜索
- 帖子和用户分别建立索引
- 数据变更时同步更新索引
