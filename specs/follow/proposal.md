# proposal：关注功能

## 需求背景

用户可以关注其他用户，建立社交关系。
关注是 Feed 流和个人中心的基础。

## 用户故事

1. 作为已登录用户，我希望关注其他用户，以便查看他们的动态
2. 作为已登录用户，我希望取消关注
3. 作为访客，我希望查看用户的关注/粉丝列表
4. 作为已登录用户，我希望查看我的关注/粉丝数量

## 功能范围

### MVP 阶段（本次实现）

- [ ] 关注用户
- [ ] 取消关注
- [ ] 查询是否已关注
- [ ] 获取关注列表
- [ ] 获取粉丝列表

### 后续迭代

- [ ] 互相关注
- [ ] 关注推荐

## 验收标准

1. 已登录用户可以关注其他用户
2. 不能关注自己
3. 重复关注返回成功（幂等）
4. 取消关注返回成功
5. 用户可以查看关注/粉丝列表

## 技术约束

- 遵循 handler → service → repo 分层
- 使用独立的 follows 表
- 使用联合唯一索引防止重复关注
