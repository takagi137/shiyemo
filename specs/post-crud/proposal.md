# proposal：发帖功能

## 需求背景

用户可以在社区发布帖子，分享情绪、认知、案例或发起行动。
帖子是社区的核心内容，支持多种类型和标签。

## 用户故事

1. 作为已登录用户，我希望发布帖子，以便分享我的想法和经历
2. 作为已登录用户，我希望编辑我的帖子，以便修正错误
3. 作为已登录用户，我希望删除我的帖子，以便移除不当内容
4. 作为访客，我希望查看帖子详情，以便了解内容
5. 作为访客，我希望浏览帖子列表，以便发现感兴趣的内容

## 功能范围

### MVP 阶段（本次实现）

- [ ] 创建帖子（支持 4 种类型）
- [ ] 获取帖子详情
- [ ] 获取帖子列表（分页、筛选、排序）
- [ ] 更新帖子
- [ ] 删除帖子（软删除）

### 后续迭代

- [ ] 帖子图片上传
- [ ] 帖子草稿
- [ ] 帖子置顶
- [ ] 帖子推荐

## 验收标准

1. 已登录用户可以创建帖子
2. 帖子创建成功后返回完整信息
3. 任何用户可以查看帖子详情
4. 帖子列表支持按类型筛选
5. 帖子列表支持按时间/热度排序
6. 只有作者可以编辑/删除自己的帖子
7. 删除后帖子不再显示

## 技术约束

- 遵循 handler → service → repo 分层
- 帖子内容存储在 PostgreSQL
- 图片 URL 存储在 JSONB 字段
- 标签存储在 JSONB 字段
- 使用软删除（deleted_at）
