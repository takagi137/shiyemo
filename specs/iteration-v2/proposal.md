# proposal：二次开发计划 - 功能迭代

## 背景

失业么 MVP 已完成（11 个模块，39 个 API），需要进行功能迭代，提升用户体验和运营效率。

## 目标

1. 增强用户主页数据展示
2. 完善通知系统（分类、批量操作、回复通知）
3. 增强搜索功能（用户搜索、标签搜索、搜索建议）
4. 支持帖子富文本编辑和图片内嵌
5. 建立内容审核队列

## 功能范围

### P1 - 功能迭代（本次开发）

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 用户主页数据 | 返回用户帖子数、关注数、粉丝数、获赞数 | 高 |
| 通知分类 | 按类型筛选（点赞/评论/关注/系统） | 高 |
| 通知批量操作 | 批量标记已读、批量删除 | 高 |
| 评论回复通知 | 被回复时发送通知 | 高 |
| 搜索增强 | 搜索用户、按标签搜索、搜索建议 | 中 |
| 帖子编辑增强 | 富文本内容、图片内嵌 | 中 |
| 内容审核队列 | 待审核帖子队列、审核历史记录 | 中 |

## 不做范围

- 推荐算法（MVP 阶段禁止）
- 即时通讯（MVP 阶段禁止）
- 支付系统（MVP 阶段禁止）

## 成功标准

- [ ] 所有功能通过 L1 + L3 验证
- [ ] 生产环境部署成功
- [ ] 无 P0 级 Bug
