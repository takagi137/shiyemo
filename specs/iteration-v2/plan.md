# 失业么 - 二次开发计划

## 开发目标

基于 MVP 完成后，进行功能迭代增强，提升用户体验和运营效率。

## 功能清单

### P1 - 功能迭代（优先级高）

| # | 模块 | 功能 | 说明 | 预估 | 依赖 |
|---|------|------|------|------|------|
| 1 | post | 帖子编辑增强 | 支持富文本内容、图片内嵌 | 2h | 无 |
| 2 | user | 用户主页数据 | 返回用户帖子数、关注数、粉丝数、获赞数 | 1h | 无 |
| 3 | search | 搜索增强 | 支持搜索用户、按标签搜索、搜索建议 | 2h | 无 |
| 4 | notification | 通知分类 | 支持按类型筛选（点赞/评论/关注/系统） | 1h | 无 |
| 5 | notification | 批量操作 | 批量标记已读、批量删除 | 1h | 无 |
| 6 | comment | 评论回复通知 | 被回复时发送通知 | 1h | 无 |
| 7 | admin | 内容审核队列 | 待审核帖子队列、审核历史记录 | 2h | 无 |

**总预估工时：10h**

## 开发顺序

```
Phase 1: 用户主页数据 (1h) - 无依赖，可立即开始
Phase 2: 通知分类 + 批量操作 (2h) - notification 模块增强
Phase 3: 评论回复通知 (1h) - 依赖 comment + notification
Phase 4: 搜索增强 (2h) - search 模块增强
Phase 5: 帖子编辑增强 (2h) - post 模块增强
Phase 6: 内容审核队列 (2h) - admin 模块增强
```

## 开发规范

- 遵循 `shiyemo-dev` skill 定义的开发流程
- 每个 Phase 完成后执行 L1 + L3 验证
- 验证通过后 Git 提交
- 遇到问题通知「任务通知群聊」
