# proposal：Android App Phase 3 — 社交功能

## 背景
- Android App Phase 1（脚手架）和 Phase 2（核心功能）已完成
- 当前 App 只能浏览帖子和个人中心，缺少社交互动能力
- 搜索、通知、关注三个模块在 Web 端已实现，后端 API 已就绪
- 需要补齐 App 端的社交功能，使移动端体验与 Web 端对齐

## 目标用户
- 使用 Android 手机访问"失业么"社区的用户

## 核心功能
1. **搜索**：关键词搜索帖子和用户，防抖输入，无限滚动分页
2. **通知**：查看点赞/评论/关注通知，标记已读，全部已读
3. **关注/取关**：在他人主页关注/取消关注用户
4. **关注/粉丝列表**：查看关注和粉丝列表，点击可跳转用户主页
5. **他人主页**：通过 userId 参数化路由查看其他用户主页

## 不做范围
- 搜索历史/热门搜索：延后到 Phase 4
- 推送通知（FCM）：延后到 Phase 4
- 实时 WebSocket 通知：延后到 Phase 4
- 关注动态 Feed Tab：后端已有 API，App 端延后

## 成功标准
- [ ] 用户可通过关键词搜索帖子和用户
- [ ] 搜索输入有 500ms 防抖，结果支持无限滚动
- [ ] 通知列表正确显示点赞/评论/关注三类通知
- [ ] 未读通知有视觉区分，支持全部已读
- [ ] 他人主页可关注/取消关注，状态即时更新
- [ ] 关注/粉丝列表支持分页加载
- [ ] 所有功能对后端 API 无侵入（复用现有接口）
