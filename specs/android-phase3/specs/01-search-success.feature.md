# spec：App 搜索 — 成功场景

## 场景描述
用户在搜索页输入关键词，获取匹配的帖子和用户结果

## 规格

### Given 搜索条件有效
- 用户已登录
- 后端存在标题包含"失业"的帖子
- 后端存在昵称包含"小"的用户

### When 用户执行搜索
- 用户在搜索框输入"失业"
- 等待 500ms 防抖结束
- 系统发送 GET /api/v1/search?q=失业&page=1&page_size=20

### Then 返回搜索结果
- 响应 code = 0
- data 列表包含匹配的帖子（type = "post"）
- data 列表包含匹配的用户（type = "user"）
- 搜索结果卡片显示标题/昵称、类型标签、内容预览
