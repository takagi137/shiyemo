# spec：静思空间 - 私密日记

## 场景描述
用户记录私密日记，只有自己能看到

## 规格

### Given 用户已登录
- 用户已认证
- 日记模块已加载

### When 用户输入日记内容并保存
- POST /api/v1/journal
- 请求体：{ "content": "今天感觉好多了..." }
- 响应状态码 200
- 返回日记 id 和创建时间
- 数据库 journal 表新增一条记录
- user_id = 当前用户 id

### When 用户查看历史日记
- GET /api/v1/journal
- 返回当前用户的所有日记（按时间倒序）
- 不返回其他用户的日记

### When 用户删除日记
- DELETE /api/v1/journal/:id
- 只能删除自己的日记
- 响应状态码 200

### When 未登录用户尝试访问日记 API
- 响应状态码 401
- 返回"未授权"错误
