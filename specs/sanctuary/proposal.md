# proposal：静思空间

## 背景
- 失业么不只是社区，更应该是**情绪栖息地**
- 用户需要一个没有社交压力的独处空间，平静思考、自我疗愈
- 社区内容（帖子/评论）可能造成比较和压力，需要一个"避风港"
- 阅读经典可以让人知道"过去的人也面临过同样的痛苦"，获得共鸣和智慧

## 目标用户
- 所有已登录用户
- 情绪低落需要独处的用户
- 想要平静思考的用户
- 想从经典中获取智慧的用户

## 核心功能
1. **呼吸练习**：可视化呼吸引导动画，帮助用户放松
2. **环境音**：4-6种背景音效可选（雨声/钢琴/森林/海浪/篝火/白噪音）
3. **私密日记**：仅自己可见的文字输入，情绪出口
4. **今日阅读**：每日一篇经典片段 + 背景故事解读
5. **每日文案**：一句温暖的话

## 不做范围
- 不实现社交功能（无点赞/评论/分享）
- 不实现日记分享（纯私密）
- 不实现阅读笔记（后续单独做）
- 不实现音乐上传（使用预置音频）

## 成功标准
- [ ] 用户能进入 /sanctuary 页面
- [ ] 呼吸练习动画正常运行（扩大→缩小循环）
- [ ] 环境音能播放/暂停/切换
- [ ] 日记能保存并回看
- [ ] 每日阅读能展示经典片段
- [ ] 页面零社交（无他人内容/头像/数据）
- [ ] 移动端和桌面端都能正常使用
