# spec：查看他人主页 - 成功场景

> 所属模块：用户 (user)
> 优先级：P0

## 场景描述
已登录用户点击帖子作者头像，跳转到他人主页，查看用户信息和帖子列表。

## 规格

### Given 用户已登录，存在其他用户
- 用户已登录，token 有效
- 目标用户 ID=2，昵称="张三"，有 5 篇帖子

### When 访问 /users/2
- 页面发起 3 个请求：
  - GET /api/v1/users/2
  - GET /api/v1/users/2/stats
  - GET /api/v1/users/2/posts?page=1&page_size=20

### Then 页面展示
- 用户信息区：头像、昵称、简介
- 统计区：发帖数=5、获赞数=N、关注数=N、粉丝数=N
- 帖子列表：展示该用户的帖子卡片
- 关注按钮：显示"关注"或"已关注"状态
