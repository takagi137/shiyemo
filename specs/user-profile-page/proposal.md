# proposal：他人主页

## 背景
- 用户点击帖子作者头像/昵称，无法查看对方的个人页面
- 社区的基础交互缺失，无法浏览他人的帖子和成果

## 目标用户
- 所有登录/未登录用户

## 核心功能
1. 展示用户基本信息（头像、昵称、简介）
2. 展示用户统计数据（发帖数、获赞数、关注/粉丝）
3. 展示用户的帖子列表（分页）
4. 关注/取消关注按钮（登录用户）
5. 展示用户的技能标签

## 不做范围
- 用户时间线聚合：延后到 P2
- 私信功能：不在 Phase1 范围

## 成功标准
- [ ] 点击头像可跳转到 /users/[id]
- [ ] 页面展示用户信息、统计数据、帖子列表
- [ ] 登录用户可关注/取消关注
- [ ] 帖子列表分页正常
