# proposal：用户资料功能

## 需求背景

用户注册登录后，需要完善个人资料，包括头像、昵称、个人简介、前公司、职业等信息。
其他用户可以通过个人主页了解该用户。

## 用户故事

1. 作为已登录用户，我希望查看自己的个人资料，以便了解当前信息
2. 作为已登录用户，我希望编辑自己的个人资料，以便完善个人信息
3. 作为已登录用户，我希望上传头像，以便展示个人形象
4. 作为访客，我希望查看其他用户的公开资料，以便了解对方

## 功能范围

### MVP 阶段（本次实现）

- [x] 获取当前用户资料（已实现）
- [ ] 获取指定用户公开资料
- [ ] 更新用户资料（昵称、简介、公司、职业）
- [ ] 上传头像（本地存储）

### 后续迭代

- [ ] 用户主页（帖子列表、关注、粉丝）
- [ ] 技能标签
- [ ] 个人简介富文本

## 验收标准

1. 已登录用户可以获取自己的完整资料
2. 任何用户可以获取其他用户的公开资料（隐藏敏感信息）
3. 已登录用户可以更新自己的资料
4. 更新后资料立即生效
5. 头像上传成功后返回访问 URL

## 技术约束

- 遵循 handler → service → repo 分层
- 头像存储在本地文件系统（MVP 阶段）
- 不引入新的中间件
