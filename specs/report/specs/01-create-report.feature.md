# 举报功能 BDD 场景

## 场景 1: 用户举报帖子

**Given** 用户已登录
**And** 存在一个帖子（ID: 123）

**When** 用户提交举报请求
```json
{
  "target_type": "post",
  "target_id": 123,
  "reason": "该帖子包含违规内容"
}
```

**Then** 响应状态码为 200
**And** 响应体包含
```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "target_type": "post",
    "target_id": 123,
    "reason": "该帖子包含违规内容",
    "status": 1
  }
}
```

---

## 场景 2: 用户重复举报同一帖子

**Given** 用户已登录
**And** 用户已举报过帖子（ID: 123）

**When** 用户再次举报同一帖子

**Then** 响应状态码为 400
**And** 响应体包含错误码 400xx

---

## 场景 3: 管理员查看举报列表

**Given** 管理员已登录
**And** 存在多条举报记录

**When** 管理员请求举报列表
```
GET /admin/reports?page=1&page_size=20
```

**Then** 响应状态码为 200
**And** 响应体包含举报列表

---

## 场景 4: 管理员处理举报

**Given** 管理员已登录
**And** 存在一条待处理的举报（ID: 1）

**When** 管理员处理举报
```json
{
  "status": 2,
  "handle_reason": "已删除违规帖子"
}
```

**Then** 响应状态码为 200
**And** 举报状态更新为"已处理"

---

## 场景 5: 管理员驳回举报

**Given** 管理员已登录
**And** 存在一条待处理的举报（ID: 1）

**When** 管理员驳回举报
```json
{
  "status": 3,
  "handle_reason": "内容不违规"
}
```

**Then** 响应状态码为 200
**And** 举报状态更新为"已驳回"

---

## 场景 6: 未登录用户举报

**Given** 用户未登录

**When** 用户尝试举报

**Then** 响应状态码为 401
**And** 响应体包含错误码 401xx

---

## 场景 7: 举报不存在的帖子

**Given** 用户已登录

**When** 用户举报不存在的帖子（ID: 999）

**Then** 响应状态码为 404
**And** 响应体包含错误码 404xx

---

## 场景 8: 举报原因为空

**Given** 用户已登录

**When** 用户提交举报请求，但原因为空
```json
{
  "target_type": "post",
  "target_id": 123,
  "reason": ""
}
```

**Then** 响应状态码为 400
**And** 响应体包含参数错误

---

## 场景 9: 举报原因超过 500 字

**Given** 用户已登录

**When** 用户提交举报请求，但原因超过 500 字

**Then** 响应状态码为 400
**And** 响应体包含参数错误

---

## 场景 10: 非管理员查看举报列表

**Given** 普通用户已登录

**When** 用户请求举报列表

**Then** 响应状态码为 403
**And** 响应体包含权限错误
