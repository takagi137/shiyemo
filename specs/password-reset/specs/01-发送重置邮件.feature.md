# spec：发送重置邮件 - 成功场景

> 所属模块：认证 (auth)
> 优先级：P1

## 场景描述
用户忘记密码，输入注册邮箱，系统发送密码重置邮件。

## 规格

### Given 用户已注册
- 数据库 users 表存在 email="test@example.com" 的用户

### When 提交忘记密码请求
- POST /api/v1/auth/forgot-password
- 请求体：{ "email": "test@example.com" }

### Then 邮件发送成功
- 响应状态码：200
- Redis 中存储 reset_token，TTL=15分钟
- 用户收到包含重置链接的邮件
