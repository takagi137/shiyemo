# spec：重置密码 - 成功场景

> 所属模块：认证 (auth)
> 优先级：P1

## 场景描述
用户点击邮件中的重置链接，输入新密码完成重置。

## 规格

### Given 重置 token 有效
- Redis 中存在有效的 reset_token
- token 未过期

### When 提交重置密码请求
- POST /api/v1/auth/reset-password
- 请求体：{ "token": "xxx", "new_password": "newpass123" }

### Then 密码重置成功
- 响应状态码：200
- 数据库 users 表 password_hash 已更新
- Redis 中 token 被删除
- 用户可用新密码登录
