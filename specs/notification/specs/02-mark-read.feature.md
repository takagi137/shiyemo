# 场景：标记已读

## 场景 1：标记单条通知已读

### 前置条件
- 用户已登录
- 存在一条未读通知

### 测试步骤
1. 发送 PUT 请求到 `/api/v1/notifications/:id/read`
2. 携带有效的 JWT token

### 预期结果
- 状态码：200
- 该通知的 is_read 变为 true
- 未读数量减少 1

---

## 场景 2：标记全部通知已读

### 前置条件
- 用户有 5 条未读通知

### 测试步骤
1. 发送 PUT 请求到 `/api/v1/notifications/read-all`

### 预期结果
- 状态码：200
- 所有通知的 is_read 变为 true
- 未读数量变为 0

---

## 场景 3：标记已读通知不影响状态

### 前置条件
- 存在一条已读通知

### 测试步骤
1. 发送 PUT 请求到 `/api/v1/notifications/:id/read`（该通知已读）

### 预期结果
- 状态码：200（幂等）
- 未读数量不变
